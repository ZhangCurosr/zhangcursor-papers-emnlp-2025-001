# 论文速读：CiteBART-Learning-to-Generate-Citations-for-Local-Citation-R

## 一句话总结
本文提出CiteBART，一种基于BART架构的端到端生成式局部引用推荐（LCR）模型。通过将作者-日期引用占位符掩码并学习自回归重建，该方法无需传统“预取+重排”流水线，在多个LCR基准上达到SOTA，并首次系统性地量化了生成式引用的幻觉行为。

## 研究问题与动机
- **核心问题**：为科学论文局部文本上下文中的引用占位符（如`(Author, Year)`）推荐最匹配的候选参考文献集合。
- **现有方法不足**：
  1. 主流方案（DualEnh、HAtten、SymTax）依赖两阶段“预取+重排”流水线，检索与排序解耦，难以端到端联合优化。
  2. 既有工作通常在推理时强行拼接被引论文的标题/摘要作为额外特征，违背实际写作辅助场景中“被引未知”的前提。
  3. 基于纯编码器（BERT/SciBERT）的方法受限于词表匹配，无法直接输出长格式的引用串，且难以建模引用生成的时序依赖。

## 核心贡献（创新点）
1. **提出端到端生成式LCR框架CiteBART**：彻底摒弃预取重排范式，直接通过掩码填充生成结构化引用串，推理时完全不依赖被引论文元数据。
2. **设计Base与Global双策略自回归预训练**：Global方案受REALM启发，将施引论文的标题与摘要追加至局部上下文进行联合编码，使模型隐式学习全局语境与局部引用的关联，而非显式检索。
3. **构建引用幻觉分类体系与量化指标**：首次针对生成式LCR定义MaHR/MiHR及细粒度错误类型（如年份错误、部分作者匹配等），揭示“部分正确”幻觉的泛化价值及GT命中对幻觉率的显著抑制效应。
4. **消融验证训练-推理信息边界的合理性**：证实局部上下文是推荐的决定性因素，并指出在训练期错误引入被引论文信息会导致测试期因信息缺失而性能崩塌，明确了生成式单向预测的优越性。

## 方法详解
- **基础架构**：以开源BART-base为骨干（编码器-解码器结构），继承其文档去噪预训练机制（随机词掩码、span掩码、句置换等）。
- **自定义引用掩码目标**：将原数据集中的`TARGETCIT`标记统一替换为`<mask>`令牌。模型学习根据上下文自回归生成对应的作者-日期引用序列（如`Smith et al., 2020`），损失函数为标准序列交叉熵：$\mathcal{L} = -\sum_{t} \log P(w_t | w_{<t}, \text{context})$。
- **Base vs Global训练策略**：
  - **Base**：输入仅包含局部上下文（含`<mask>`）。
  - **Global**：借鉴REALM思想，使用`</s>`分隔符将施引论文的标题与摘要拼接至局部上下文后。反向传播信号穿过全局信息，使模型学习与全语料库的关联；推理时仅输入待预测上下文。
- **生成约束**：采用grouped beam search（beam数=20），多样性惩罚系数=1.5，最大生成长度=25 token，直接输出Top-10候选引用，无需外部检索器参与。

## 实验与结果
- **数据集**：ACL-200（30k训练）、PeerRead（9k训练）、RefSeer（3.5M训练）、ArXiv（3.0M训练）。均清洗去除了作者名冲突、顺序错误及非目标引用。
- **评估基线**：BM25、BERT-GCN、DualEnh-ws、HAtten、SymTax。
- **主要指标**：Recall@10 (R@10)、Mean Reciprocal Rank (MRR)、Exact Match (EM)。
- **核心结果**：
  - **CiteBART-Global**在ACL-200（R@10=0.739, MRR=0.513）、Refseer（R@10=0.652, MRR=0.479）和ArXiv（R@10=0.502, MRR=0.305）上全面超越所有基线，其中Refseer相比HAtten提升最为显著（R@10从0.339跃升至0.652）。
  - 仅在规模较小的PeerRead上（R@10=0.669, MRR=0.502）与SOTA持平/略低，作者归因于小数据难以充分发挥生成式预训练的容量优势。
  - **幻觉分析**：ACL-200 Global模型在Top-3预测的宏观幻觉率（MaHR）低至4%；当GT出现在Top-k内时，其余预测的幻觉倾向统计显著下降（p<0.001），ArXiv Global模型在此方面表现最优。

## 相关工作脉络
1. **BERT-GCN (Jeong et al., 2020)**：结合BERT局部编码与GCN引用图结构。本文与其定位差异在于完全放弃图构建与会话历史，转为纯生成式单向预测，更适合动态扩展的新文献库。
2. **HAtten / SymTax (Gu et al., 2022; Goyal et al., 2024)**：代表“预取+重排”主流范式，推理时强依赖候选被引论文的标题/摘要。CiteBART的本质突破在于生成式单步填充，避免了检索阶段的截断误差，且更符合写作时的信息可得性。
3. **SPECTER / SciBERT (Cohan et al., 2020; Beltagy et al., 2019)**：专注于论文级向量表示，用于分类或全局引用排序。CiteBART聚焦细粒度上下文内的引用串生成，任务目标从“相似度打分”转向“结构化文本生成”。
4. **REALM (Guu et al., 2020)**：检索增强语言模型预训练框架。CiteBART-Global的设计直接受其启发，但摒弃了显式检索器，改用全局语境拼接+联合反向传播实现更轻量的知识对齐。

## 局限性与未来方向
- **局限性**：
  1. 依赖“上下文已包含引用占位符”的强假设，无法处理开放式引用发现。
  2. 需在特定数据集上持续预训练，语料外的重要工作可能被遗漏；生成式幻觉（尤其是完全虚构的fabrication）仍客观存在。
  3. 当前仅支持单引用占位符，主流基准均未提供多引用共现的完整元数据，难以直接扩展至真实的多引用上下文。
  4. 过度利用施引论文全局信息可能引入对高频作者的引用偏好偏差。
- **未来方向**：探索自定义掩码填充与生成式信息检索（Generative IR）中检索token识别的关联；研究针对性缓解引用幻觉的算法；构建支持多引用共现的LCR基准数据集；尝试均衡利用施引论文、局部上下文与被引论文三要素的联合学习机制。
