# 论文速读：SurveyGen-Quality-Aware-Scientific-Survey-Generation-with-La

## 一句话总结
本文构建了包含 4200+ 篇人工综述的大规模 SurveyGen 数据集，并提出 QUAL-SG 质量感知检索框架，通过在 RAG 流程中引入共被引扩展和文献质量重排序，显著提升了自动科学综述生成中的引用质量与整体内容质量。

## 研究问题与动机
1. **高质量文献检索不足**：现有 RAG 方法仅依赖语义相似度检索，无法识别低影响力或边缘研究，导致生成的综述引用可靠性差。
2. **缺乏大规模标准评估数据集**：当前工作缺少可与人工撰写的"金标准"综述进行系统性对比的大规模评测基准，引用质量、结构一致性等维度尚未被充分探索。
3. **引用质量评估偏重召回率**：已有研究主要评估引用召回率（Recall），但高召回率可能掩盖大量无关引用，需要同时引入精确率以平衡评估。
4. **人类介入程度的系统对比缺失**：不同自动化程度（完全 LLM 生成 vs. RAG vs. 人工指导）下的性能差异尚未被系统性评测。

## 核心贡献（创新点）
1. **SurveyGen 大规模综述数据集**：构建 4200+ 篇跨学科人工综述及 242,143 个引用与丰富元数据，首个支持多维度引用质量评估的综合基准，区别于仅有 CS 领域数据的 SciReviewGen。
2. **QUAL-SG 质量感知 RAG 框架**：在检索阶段引入共被引扩展与基于主题相关性、学术影响力、内容多样性的三维重排序机制，比 Naive-RAG 在引用 F1 上提升 10.80%，本质区别在于将文献质量指标显式融入检索流程而非仅依赖语义匹配。
3. **三任务分层评测体系**：定义完全 LLM 生成（Task 1）、标准 RAG（Task 2）和人工指导（Task 3）三种任务设置，首次系统对比不同人类介入程度下 6 个 SOTA LLM 的全面性能。
4. **多维度量化评估指标**：引入引用精确率（Precision）、Key Point Recall（KPR）及结构重叠度，使评估更全面，弥补了以往仅用召回率评估引用质量的缺陷。

## 方法详解
**三任务设计**：Task 1 仅输入主题生成大纲与内容；Task 2 先通过 RAG 检索相关论文再分步生成；Task 3 直接使用人工筛选的参考文献与大纲，模拟真实写作场景。

**数据集构建流程**：从 S2ORC 筛选标题含"survey/review"关键词的论文，通过三个 LLM 多投票过滤非综述文章，去除参考文献少于 30 篇或章节少于 3 篇的短文，最终得到 4205 篇。补充 OpenAlex 元数据（引用数、h-index、期刊声誉等），并二跳扩展至 506 万条二级引用。

**QUAL-SG 检索流程**：
- 语义检索：使用 bge-large-en-v1.5 计算主题与摘要的余弦相似度，选取 top-n 候选集 D。
- 共被引扩展：将被 D 中至少两篇论文共同引用的文章加入，形成 D_ex。
- 三维重排序：对 D_ex 中每篇论文计算（1）主题相关性分数 S_t（LLM-as-judge）；（2）学术影响力分数 S_a = α·C + β·A + γ·V（引用性能、作者影响力、期刊声誉，权重分别为 0.2、0.3、0.5）；（3）内容多样性分数 S_d（平均语义距离）。最终按三分数的平均排名选取 top-κ 篇，κ 与人工综述实际引用数对齐。

**评估指标**：引用质量（Precision/Recall/F1，匹配阈值 0.95）；内容质量（语义相似度、ROUGE-L、KPR）；结构一致性（章节重叠率、LLM-as-judge 相关性评分）。

## 实验与结果
**数据集**：120 篇精选综述（生物/医学/心理学/计算机科学各 30 篇），涵盖 4 个学科领域。

**评估基线**：Fully-LLMGen（Tang et al., 2025）、Naive-RAG（Wu et al., 2025）、Human-written；对比模型包括 GLM-4-Flash、LLaMA-3.1-70B、DeepSeek-V3、GPT-4.1、Gemini-2.0-Flash、Claude-3.7-Sonnet。

**主要结果**：
- Task 1：Claude-3.7-Sonnet 引用 F1 最高（7.76%），LLaMA-3.1-70B 内容相似度最高（82.43%）；所有模型引用准确率均低于 36%， hallucination 问题严重。
- **Task 2（核心对比）**：QUAL-SG 引用 F1 达 **16.73%**，显著优于 Naive-RAG（5.93%，+10.80%）和 Fully-LLMGen（7.76%，+8.97%）；内容相似度（83.10% vs 82.37%）和 KPR（50.25% vs 42.17%）亦有提升；结构重叠度达 **24.76%**，较 Naive-RAG 提升 12.54 个百分点。
- Task 3：LLaMA-3.1-70B 内容相似度达 84.39%，Claude-3.7-Sonnet KPR 最高（54.67%）。
- 消融实验：移除共被引扩展 F1 下降 5.98%，移除学术影响力排序 F1 下降 7.72%，证明两者最关键。
- 与 RankGPT/UPR 对比：QUAL-SG 引用 F1（16.73%）优于 RankGPT（14.81%）和 UPR（10.45%）。

**最强结果**：QUAL-SG 在 Task 2 上综合表现最佳，引用 F1 较 Naive-RAG 提升近 3 倍，结构重叠度提升约 2 倍。

## 相关工作脉络
1. **SciReviewGen（Kasanishi et al., 2023）**：首个大规模综述生成数据集（10.2K 篇 CS 领域），但缺乏多学科覆盖和引用质量元数据，本文在其基础上扩展了学科范围和质量评估维度。
2. **AutoSurvey（Wang et al., 2024）**：两阶段 RAG 综述生成方法，本文相比之下提供了更全面的多任务评测基准和引用精确率指标。
3. **SurveyX（Liang et al., 2025）**：使用在线检索和 AttributeTree 预处理，本文强调质量感知重排序而非仅依赖检索策略。
4. **LitLLM（Agarwal et al., 2025）**：聚焦文献检索工具，本文将其扩展至完整的综述生成流水线并进行系统评测。
5. **UPR（Sachan et al., 2022）/RankGPT（Sun et al., 2023）**：通用 RAG 重排序方法，本文针对学术综述场景设计了定制化质量指标组合。

## 局限性与未来方向
1. **输入限制**：因版权原因仅使用摘要而非全文，限制了内容的深度和完整性。
2. **缺少后处理环节**：未进行语言润色、引用格式调整、PDF/LaTeX 导出等后处理，也未包含图表等视觉元素。
3. **数据污染风险**：开源综述可能已进入 LLM 训练数据，影响评测结果的准确性。
4. **评测样本范围有限**：仅使用 120 篇较短综述，期望在完整数据集上验证趋势的一致性。
5. **未来方向**：引入全文理解、引用行为建模、人类在环的话语控制与事实一致性验证、长文档建模等。

## 研究启发与可借鉴点
1. **质量感知检索框架的可迁移性**：QUAL-SG 的"共被引扩展 + 多维质量重排序"策略可推广至其他需要精准文献引用的学术生成任务（如论文引言撰写、研究方法综述）。
2. **三任务分层评测设计值得借鉴**：通过不同人类介入程度设置对比任务，为评测 LLM 在长文本生成任务中的能力边界提供了清晰的方法论参考。
3. **引用精确率与召回率的联合评估**：纠正了以往仅关注召回率的偏差，为引用相关的 NLP 任务提供了更平衡的评估范式。
4. **跨学科一致性验证**：报告了模型在不同学科间的稳定表现（ANOVA 检验），为跨领域模型泛化性评估提供了范例。
5. **开源数据集的基准价值**：SurveyGen 可作为后续研究的标准评测平台，促进该领域的系统性进步。

## 关键术语表
**SurveyGen**：包含 4200+ 篇跨学科人工综述的大规模数据集，附带引用关系和丰富元数据，用于支撑科学综述生成任务的研究与评测。

**QUAL-SG**：质量感知文献检索框架，在 RAG 基础上通过共被引扩展和三维重排序（主题相关性、学术影响力、内容多样性）提升检索文献质量。

**Key Point Recall (KPR)**：衡量生成综述是否覆盖人工综述中关键信息点的指标，通过 LLM 提取关键点后进行 QA 匹配评估。

**共被引扩展（Co-citation Expansion）**：将被候选集中至少两篇论文共同引用的文章纳入检索池的策略，用于捕捉语义不直接相关但学术影响力高的奠基性工作。

**LLM-as-judge**：使用大语言模型作为裁判对文本质量、相关性等主观维度进行自动评分的评估方法。

**学术影响力分数（S_a）**：由引用性能（C）、作者影响力（A）和期刊声誉（V）加权组合的文献质量指标。
