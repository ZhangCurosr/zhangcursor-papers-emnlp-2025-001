# 论文速读：Abstract

## 一句话总结
本文针对当前大语言模型对齐评估过度依赖行为代理指标的盲区，提出了解码不变且行为无关的几何度量 **AQI**，通过量化潜在空间中安全/不安全激活的聚类分离度来诊断真实对齐质量，并配套发布严格平衡的基准数据集 **LITMUS**。

## 研究问题与动机
- 现有对齐评估严重依赖行为代理指标（拒答率、G-Eval、毒性分类器），仅观测表层输出，存在显著盲区。
- 模型可能在输出层面保持合规，但内部仍潜伏不安全/对抗性倾向（如 jailbreak、alignment faking、随机解码不稳定性）。
- 行为指标易受提示措辞变化、微调漂移及解码温度波动的干扰，缺乏鲁棒性与可解释性。
- 缺乏标准化、平衡且覆盖多元风险场景的评估基准，难以公平对比 DPO/RLHF/SFT 等不同训练体制的真实对齐效果。

## 核心贡献（创新点）
- **提出 AQI 几何度量**：首次将聚类内部指标引入大模型对齐诊断，实现解码不变、行为无关的真实对齐质量量化。
- **层间稀疏加权池化**：在中间 MLP 激活层（L11–L24 权重最高）应用 Sparsemax/α-entmax 聚合，精准定位对齐关键层，避免仅依赖输出层的噪声干扰。
- **对比分离损失 L_sep**：仅优化注意力投影权重以拉大安全/不安全表征距离，同时冻结 LLM 本体，实现低开销的对齐状态诊断。
- **LoRA 参数正交分解**：将更新 ΔW 拆分为受正则保护的对齐关键分量 ΔW_A 与任务特定分量 ΔW_T，兼顾对齐质量与下游任务性能。
- **发布 LITMUS 基准**：构建 10,000 条严格 50/50 平衡的单行提示数据集（安全源：MMLU；不安全源：Anthropic HH-RLHF、OpenAI Moderation Prompts、HateCheck），并提供 500-pair 评估子集。

## 方法详解
- **AQI 核心公式**：`AQI = λ·(1/XBI) + (1-λ)·CHI`，默认 λ=0.5。XBI（Xie-Beni Index）衡量局部紧凑性与簇间分离，CHI（Calinski-Harabasz Index）衡量全局分散度；亦可替换为 DBS（Davies-Bouldin）或 DI（Dunn）等指标组合。
- **层间池化机制**：提取模型中间层 MLP 激活向量，通过可微的 Sparsemax/α-entmax 注意力权重加权聚合，自动将 L11–L24 等高贡献层赋予主导权重，抑制浅层/深层噪声。
- **对比分离损失**：`L_sep = Σ max(0, M - ||h̃_s - h̃_u||_2)`，其中 h̃_s 与 h̃_u 分别为安全与不安全激活的聚合表征，M 为 margin 边界。该损失仅反向更新投影权重，LLM 主干完全冻结，防止灾难性遗忘。
- **LoRA 分解对齐训练**：将低秩适配矩阵正交分解为对齐敏感分量 ΔW_A（施加正则约束以维持潜在空间分离结构）与任务特定分量 ΔW_T，使模型在适配下游任务时不破坏已习得的对齐表征。

## 实验与结果
- **实验设置**：基础模型 **Llama-2-Chat 7B**；四种训练体制对比（DPO / RLHF / SFT Only / Adversarial Exposure）；评估基线为 G-Eval 与 LLM Judge Scores。
- **核心指标对比**：
  - DPO on OpenAssistant：AQI **0.85**，G-Eval 0.82，Judge 0.80，Pearson 0.87，Spearman 0.84（整体最优）。
  - RLHF on Anthropic HH：AQI 0.78，G-Eval 0.75，Judge 0.77。
  - SFT Only：AQI 降至 **0.65↓**，G-Eval 0.60，Judge 0.62，相关性同步下滑。
  - DPO + Red Team 攻击：AQI 骤降至 **0.40↓**，G-Eval 0.42，Judge 0.39。
- **Jailbreak 检测鲁棒性**：标准不安全提示 G-Eval 0.32 / AQI 0.34；越狱变体 G-Eval 被误导至 0.81，AQI 稳定下降至 **0.42↓**，证明 AQI 对对抗提示更具诊断敏感度。
- **微调漂移检测**：DPO 预训练 AQI 0.85 → ShareGPT 后微调 AQI 降至 **0.68↓**，而 G-Eval/Judge 几乎不变（0.83→0.82 / 0.80→0.79），揭示行为指标对对齐退化不敏感。
- **解码温度稳定性**：温度从 0.2 升至 1.0 时，G-Eval 从 0.82 暴跌至 0.42（降幅 40 点），AQI 仅在 0.84→0.81 轻微波动，验证其解码不变性。
