# 论文速读：Effective-Red-Teaming-of-Policy-Adherent-Agents

## 一句话总结
本文针对面向任务的LLM智能体在严格业务策略约束下的安全问题，提出了一种名为 **CRAFT** 的多智能体红队攻击框架，通过策略感知的推理与欺骗性规划，系统性地诱导策略遵循型智能体违反业务规则；同时基于 τ-bench 构建了针对性的安全评测基准 τ-break，并验证了现有轻量级防御手段的局限性。

## 研究问题与动机
1. **现有基准假设用户合作，无法评估对抗性攻击风险**：τ-bench 等现有评测基准假设用户是合作的、非策略性的，但真实场景中恶意用户会主动尝试绕过策略限制以谋取私利，导致现有评估低估了智能体的安全风险。
2. **通用攻击方法对策略遵循型智能体效果有限**：传统 jailbreak 方法（如 DAN、情绪操纵、直接提示注入）在面向通用 LLM 时可能有效，但面对必须严格遵守领域策略的智能体时，这些表层攻击手段难以奏效，无法揭示真实的策略违规漏洞。
3. **策略遵循型智能体在高价值场景中的安全需求迫切**：客服、医疗、金融等高风险领域广泛部署具备工具调用能力的 LLM 智能体，这些智能体必须执行退款、订单取消等敏感操作，任何策略违规都可能导致严重的法律或财务后果，亟需针对性的安全评估体系。

## 核心贡献（创新点）
1. **提出 CRAFT 多智能体红队框架**：设计了包含 PolicyAnalyzer、DeceptionPlanner、AvoidanceAdvisor 和 DialogueExecutor 四个模块的协同攻击系统，显式利用策略知识进行多轮对抗规划，与传统通用攻击形成本质区别。
2. **构建 τ-break 安全评测基准**：通过两种机制将任务完成型基准转换为安全评测基准——航空领域使用策略无关智能体提取违规动作集合（ΔA = A_free \ A_gold），零售领域引入额外认证策略并重新标注，为策略违规检测提供系统化测试集。
3. **发现强攻击者不等于强防御者**：揭示了模型作为攻击者的能力与其作为目标智能体的鲁棒性之间无正相关关系，例如 Qwen2.5-70B 是有效攻击者但同时是最脆弱的目标。
4. **评估并揭示轻量级防御方法的局限性**：测试了层次提示、完整策略提醒、相关策略片段提醒三种防御手段，发现即使在 k=4 时最强防御（相关片段提醒）的 ASR 仍超过 80%，表明现有简单干预不足以抵御策略感知型攻击。

## 方法详解
**CRAFT 框架包含四个核心模块，协同完成策略违规诱导：**

1. **PolicyAnalyzer（策略分析器）**：接收用户请求和完整策略文档，提取与当前请求相关的策略片段（精确复制原文，不改写），为后续攻击规划提供策略知识基础。其 prompt 要求仅输出 exact substrings，避免模型自行解读。

2. **DeceptionPlanner（欺骗规划器）**：基于用户请求和提取的策略片段，生成具体的攻击策略指令。核心策略是"反事实框架"（counterfactual framing），即生成格式为"Assume <A>"的指令，让目标智能体假设某个虚假前提（如"已购买保险"），从而合理化违规请求。

3. **AvoidanceAdvisor（规避顾问）**：定义攻击中应避免的内容，防止披露会触发策略拒绝的关键事实（如"经济舱不可取消"）。以"Do not say <A>"格式输出具体、可操作的规避指令，确保攻击不会因暴露真相而失败。

4. **DialogueExecutor（对话执行器）**：负责实际与目标智能体交互，根据规划器的指令动态调整响应，结合反事实假设与策略规避实现多轮对话。

**τ-break 数据集构建方法：**
- **航空领域**：运行策略无关智能体（policy-free agent）对每个 τ-bench 任务执行，比较其与 gold 标签的动作差异 ΔA = A_free \ A_gold，人工审查后筛选出 20 个包含实质性策略违规的测试用例。
- **零售领域**：在原始策略中新增认证要求（必须先调用 verify_user_secret 工具验证用户身份），将原本合规的请求重新标注为违规场景，生成 30 个新测试用例。

**评估指标**：采用 pass@k 指标衡量攻击成功率，定义为 k 次独立试验中至少有一次成功攻击的概率，其中 pass@1 即标准 ASR（c/n，c 为成功次数，n=4）。

## 实验与结果
**实验设置**：评估 5 个模型（GPT-4o、GPT-4o-mini、Qwen2.5-70B、LLaMA-3.3-70B、DeepSeek-V3），在 τ-break 的航空（20 个）和零售（30 个）领域上进行测试，每个请求运行 n=4 次独立试验。

**核心结果**：
- **航空领域 ASR（pass@1）**：CRAFT 达到 **70.0%**，远超 emotional manipulation（50.0%）、DPI（47.5%）、insist（47.5%）、benign user（42.5%）和 DAN（35.0%）。
- **零售领域 ASR（pass@1）**：即使面对简单的认证策略，CRAFT 对 GPT-4o 的 ASR 仍达 2.5%，对 Qwen2.5-70B 高达 31.7%。
- **最强攻击者-目标组合**：Qwen2.5-70B 作为攻击者对 GPT-4o-mini 的 ASR 达 73.8%；GPT-4o 作为攻击者对 Qwen2.5-70B 的 ASR 达 80.0%。
- **k=4 时的收敛趋势**：所有防御方法在 CRAFT 攻击下 ASR 均趋近于 90% 以上，表明足够多次尝试后攻击几乎必然成功。

**防御方法效果**：
- 最佳防御"Relevant Policy Fragments Reminder"在 k=1 时将 ASR 从 70.0% 降至 36.2%（GPT-4o 目标），但 k=4 时仍升至 55.0%。
- "Hierarchy Prompt"在某些情况下甚至无效（如 GPT-4o-mini 在 k=2 时 ASR 从 76.7% 升至 82.5%）。

**消融实验**：移除 PolicyAnalyzer 使 ASR 从 70.0% 降至 55.0%，移除 DeceptionPlanner 降至 46.6%，证明策略推理和欺骗规划缺一不可。

## 相关工作脉络
1. **τ-bench (Yao et al., 2024)**：首个大规模策略遵循智能体评测基准，评估多轮对话、工具调用与业务规则遵循能力，但假设用户合作，本文将其扩展为安全评测基准。
2. **AgentSafetyBench / AgentHarm (Andriushchenko et al., 2024; Levy et al., 2024)**：评估智能体安全性的基准，但未显式建模策略遵循场景中的领域特定约束违规。
3. **DAN 攻击 (Shen et al., 2024)**：通用 jailbreak 方法，通过角色扮演绕过内容策略，但对必须执行特定工具调用的策略遵循智能体效果有限（ASR 仅 35%）。
4. **情绪操纵攻击 (Vinay et al., 2024)**：利用情感诉求施压，在通用 LLM 中有效，但在策略明确拒绝的场景下效果下降（ASR 50% vs CRAFT 70%）。
5. **间接提示注入 IPI (Abdelnabi et al., 2023)**：针对集成 LLM 的应用程序的注入攻击，关注外部输入污染，而非策略违规诱导。
6. **Foot-in-the-door 攻击 (Nakash et al., 2025)**：逐步诱导智能体妥协的攻击模式，与 CRAFT 的持久坚持策略类似，但 CRAFT 显式结合策略知识进行多轮规划。

## 局限性与未来方向
1. **防御效果有限**：所有轻量级防御方法均无法彻底阻断 CRAFT 攻击，k=4 时 ASR 仍超 80%，表明需要更强的训练级或架构级解决方案。
2. **合成环境局限性**：实验在完全合成环境中进行（基于 τ-bench 派生），可能无法捕捉真实用户行为的复杂性、模糊性和对抗创造性。
3. **策略静态且简单**：仅评估了航空和零售两个领域的简单静态策略，未涉及法律、医疗等领域的动态或多方协商场景。
4. **假设策略完全可见**：攻击者能获取完整策略文档，这在开放系统中成立，但商业系统中的策略可能不公开或仅部分可见，限制了方法的泛化性。
5. **测试用例数量有限**：τ-break 共 50 个用例（20+30），覆盖面不足，可能无法充分表征大规模部署中的行为多样性。
6. **模型覆盖有限**：仅评估 5 个模型对，未涵盖更小模型或领域专用智能体，可能遗漏特定架构的脆弱性。
7. **静态攻击策略**：攻击者不会根据历史交互结果动态调整策略，未考虑现实中对抗升级的动态博弈场景。

## 研究启发与可借鉴点
1. **从任务完成基准到安全评测的转换范式**：通过策略无关智能体提取违规动作集合的方法，为将现有任务基准快速扩展为安全评测提供了通用思路，可迁移至其他领域基准（如医疗、法律咨询）。
2. **多角色协同的红队架构设计**：CRAFT 将策略分析、欺骗规划、规避建议、对话执行分离为独立模块，各模块有明确职责，这种模块化设计便于针对性改进和消融分析。
3. **反事实框架作为核心攻击策略**："Assume <A>"的反事实指令设计简洁有效，为对抗策略遵循智能体提供了可复用的攻击模式，可探索更多类似的欺诈性预设策略。
4. **pass@k 指标在红队评估中的应用**：使用 pass@k 而非单次 ASR 更好地反映了多轮尝试下的累积风险，建议后续安全评估工作采用该指标。
5. **防御评估的系统性方法**：论文同时评估了三种防御机制并对比了 cooperative vs adversarial 设置，这种全面的防御分析方法值得借鉴，避免单一视角的结论偏差。

## 关键术语表
**CRAFT**：Constraint-aware Red-teaming with Adversarial Framing and Tactics，本文提出的多智能体红队框架，通过策略感知的推理和欺骗性规划诱导策略违规。

**Policy-adherent agents**：策略遵循型智能体，必须在复杂业务规则（如退款政策、取消规则）约束下运行的 LLM 智能体，需准确识别并拒绝违反策略的请求。

**τ-bench**：Yao 等人提出的策略遵循智能体评测基准，在航空和零售领域评估智能体的多轮对话、工具调用和规则遵循能力，假设用户合作。

**τ-break**：本文基于 τ-bench 构建的安全评测基准，通过引入违规动作标注或额外认证策略，评估智能体对抗恶意用户的鲁棒性。

**pass@k**：红队评估指标，表示 k 次独立试验中至少有一次成功攻击的概率，反映累积攻击风险而非单次随机结果。

**DeceptionPlanner**：CRAFT 的核心推理模块，生成"Assume <A>"格式的反事实指令，引导目标智能体接受虚假前提从而合理化违规请求。

**AvoidanceAdvisor**：CRAFT 的规避指导模块，定义攻击中应避免披露的关键事实（如票价类型、取消原因），防止触发策略拒绝。

**Policy-free agent**：策略无关智能体，被指示无视所有策略约束执行用户请求的代理，用于提取与 gold 标签的差异动作集合以识别潜在违规。

## 可复现要素
- **数据集**：τ-bench 公开可用，τ-break 数据构建方法详细记录在附录 C.2，但论文未明确声明 τ-break 是否开源；使用 GPT-4o 作为策略无关智能体生成违规动作。
- **代码/权重**：论文未提及代码开源；实验附录提供了详细的 prompt 模板（Box E.1-E.9）；实验环境位于 τ-bench GitHub 仓库（envs/airline/wiki.md 和 /envs/retail/wiki.md）。
- **关键超参**：对话最大轮数 30 轮；temperature=0；seed=10；每个请求运行 n=4 次独立试验；PolicyAnalyzer 和规划器使用 LLaMA-3.3-70B 固定实现。
