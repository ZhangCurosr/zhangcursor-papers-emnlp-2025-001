# 论文速读：WangchanThaiInstruct-An-instruction-following-Dataset-for-Cu

## 一句话总结
本文提出了**WangchanThaiInstruct**，一个完全由人类撰写、覆盖4个专业领域（金融、法律、医疗、零售）与7种任务类型的泰语指令跟随数据集，旨在填补低资源语言在文化敏感与垂直专业场景下的大模型评估与微调空白；实验证明，在严格控制数据量的前提下，使用原生泰语指令微调能显著且稳健地提升模型在域内及跨域基准上的表现，效果优于主流翻译指令数据集。

## 研究问题与动机
1. **评估重心偏差**：当前大模型评测高度集中于英语（如Open LLM Leaderboard、MT-Bench），泰语等低资源语言的表现缺乏系统性、可复现的benchmark。
2. **翻译数据失真**：既有东南亚基准（SEACrowd、SEA-Bench、SEA-HELM）大量依赖英语机器翻译，无法捕捉泰国特有的文化语境、行业术语与制度背景，易导致性能虚高。
3. **本土资源受限**：泰国已有的ThaiH6与ThaiCLI虽含文化数据，但均为闭源且不开放训练集；现有开源模型（如OpenThaiGPT、Typhoon）的训练指令仍严重依赖合成或翻译数据。
4. **核心研究问题**：(RQ1) 当前LLM处理泰语文化与专业指令的实际效果如何？(RQ2) 使用原生泰语数据进行指令微调能在多大程度上弥补模型的文化与专业理解鸿沟？

## 核心贡献（创新点）
1. **构建首个面向泰国文化语境与多专业领域的双用途指令数据集**：不同于仅覆盖通用对话或单一任务的现有基准，本文设计了4领域×7任务型数据集，并显式引入文化特异性标注，兼顾零样本评估与指令微调。
2. **提出三阶段人机协同质量控制流水线**：与纯众包或LLM生成管线不同，本文引入母语标注员（初稿生成）→领域专家（事实核查+文化标签）→AI研究人员（格式对齐）的三级审核机制，确保数据的学术严谨性与微调可用性。
3. **提供严格控量下的消融对照实验**：在保持总数据量与格式完全一致的前提下，隔离出“原生监督信号”的贡献，从实证角度证明原生泰语数据显著优于Alpaca/Dolly等翻译数据集。
4. **开源完整研究资产与SOTA基线权重**：公开数据集、评估脚本、训练配置及在泰国主流基准上达到SOTA的微调模型，为东南亚语言社区的后续研究提供可复现的基础设施。

## 方法详解
- **数据采集与预处理**：从86个泰国政府机构及上市公司网站采集27,351份原始文档；去除HTML标签与图像后，保留token数Top 80%的内容文档，并使用mUSE计算余弦相似度（阈值0.8）剔除高度重复文档。
- **标注流程**：通过准入考试（涵盖7种任务类型）的母语标注员根据给定文档与任务类型生成指令、答案及推理链（Creative Writing/Brainstorming/Summarization除外）；每个文档按领域分配1~2个任务类型，确保类别分布均衡。
- **三级质量控制（QC）**：
  - *标注员自查*：随机抽样10%进行交叉复核与纠错。
  - *领域专家验证*：医疗、法律、金融专家逐条核验事实准确性，拒绝不合格样本并要求提供依据；同时为每条样本添加`cultural tag`（标记是否为泰国制度/行业/语言特指内容）。
  - *AI研究人员格式审核*：确保输出符合指令微调规范（如多选题结构、完整句式QA、推理链完整性），不符合者退回重做。
- **防数据泄露设计**：训练/测试划分严格以原始文档为单位，同一文档生成的所有任务样本均归入同一集合。
- **评估协议**：采用**LLM-as-a-judge**（选用GPT-4.1作为裁判）评估客观题的事实准确性与推理质量（1-10分），主观生成题评估流畅度与连贯性；推理评分与答案准确性的Spearman秩相关系数为0.78。
- **微调配置**：基于LlamaFactory，以Llama-3.1-8B、Gemma-2-9B、SEA-LIONv2-8B为基座，将WangchanThaiInstruct与Alpaca-cleaned-52k-th、Databricks-dolly-15k-th按等比例混合；超参：LR=2×10⁻⁴（Cosine）、Batch Size=128、Max Tokens=2048、Warmup=0.1、Epochs=3；推理时Temperature=0.2，Max New Tokens=1028，使用vLLM引擎。

## 实验与结果
- **零样本评估（RQ1）**：Gemini 2.0与Qwen2.5-72B整体领先。法律领域最具挑战性（所有模型准确率均未突破73%），医疗领域表现最佳（Gemini达88.71%）。文化特异性样本普遍导致性能下降（Closed QA除外），多项选择与开放问答是难点。
- **文化 vs 通用**：自由生成类任务（Brainstorming/Creative Writing/Summarization）受文化标签影响较小；而需精确推理的事实类任务文化敏感度显著。
- **指令微调效果（RQ2）**：加入WangchanThaiInstruct后，在**31/42**种配置下全面超越仅使用翻译数据的基线；域内准确率大幅提升（如Llama-3.1-8B从26.28%升至43.38%），且在Thai LLM Leaderboard与Thai MT-Bench等跨域基准上同样稳健提升（MT Bench平均分从3.04升至3.43）。
- **数据量消融**：在严格匹配总量（2.5k~30k）的设置下，原生数据混合组依然胜出，证实增益来自数据质量与领域/文化特性而非单纯规模膨胀。
- **长上下文分析**：随输入长度递增（tail组，最长40%样本），Brainstorming、多选、开放问答与摘要任务性能显著下滑；受限于短上下文窗口的模型衰退尤甚（Sailor2-20B摘要任务下降27%）。
- **最强结果**：微调后模型在WangchanThaiInstruct测试集及Thai LLM Benchmark上刷新多项SOTA，SEA-LIONv2-8B结合原生数据后优势最为明显。

## 相关工作脉络
1. **SEACrowd / SEA-HELM**：东南亚多语言通用基准，依赖机器翻译+众包验证；本文聚焦泰国原生数据与垂直领域专家审核，弥补文化深度不足。
2. **SEA-Bench**：引入区域考试提升本地相关性，但仍以通用场景为主；本文专门针对法律、金融、医疗等专业边界构建高保真指令集
