# 论文速读：F²Bench: An Open-ended Fairness Evaluation Benchmark for LLMs with Factuality Considerations

## 一句话总结
本文提出了 **F²Bench**，一个包含 2,568 个实例的开放式公平性评估基准，覆盖 10 个主流人口群体类别及多种交叉组合；通过多轮对话诱导与公平-事实权衡两项开放式任务，揭示现有封闭式评测的局限，并为 LLM 公平性训练策略提供新见解。代码与数据集已开源。

---

## 研究问题与动机

1. **封闭式评测与现实脱节**：现有主流基准（如 BBQ、CrowS-Pairs）均采用选择题格式，与现实开放交互场景不符；且存在"最低分效应"——模型仅凭猜测即可获得部分分数，降低评测区分度与可靠性。
2. **单纯人口统计 parity 的缺陷**：多数基准将"无偏"定义为不同群体间偏好或结果相等，却忽视了由历史、社会、文化背景导致的合理分布差异（如女性占比远高于男性的护理行业）。
3. **交叉性偏见分析不足**：现有研究多聚焦单一人口类别，缺乏对多重身份属性交互产生的偏见（如性别+种族、年龄+社会经济地位）的系统分析。
4. **忽视事实性考量**：公平性评测往往不考虑客观事实与统计信息——若过分追求形式上的公平而忽视真实世界分布，可能导致模型在实际应用中偏离可靠性。

---

## 核心贡献（创新点）

1. **提出 F²Bench 开放式公平性基准**：收录 2,568 个公平性评估实例（FEI），覆盖 Gender、Race、Religion、Age、Socioeconomy、Education、LGBTQ+、Nationality、Health、Appearance 共 10 个主流人口群体，其中部分实例涉及双群体交叉设计。
   → **与已有工作的本质区别**：突破 BBQ/CrowS-Pairs 等基于有限模板和封闭式 MCQ 的评测范式，转向反映真实开放式人机交互的生成式评估。

2. **设计两项开放式评估任务**：多轮对话诱导任务（MDI）模拟渐进式偏见注入的对话场景；公平-事实平衡任务（FFB）同时衡量模型在避免刻板印象与尊重事实之间的权衡能力，并引入 FF1 综合分数。
   → **与已有工作的本质区别**：区别于 BiasAsker 等仅用简单提示语探测偏见的对话式评估，本文通过 6 轮渐进诱导与客观事实 grounding 实现更细粒度的公平性量化。

3. **揭示开放式与封闭式评测结果的显著差异**：例如 Qwen2.5-0.5B 在 CrowS-Pairs 上表现"低偏"，但在 MDI 中得分极低（3.63），说明小模型在开放式多轮推理中更易被偏见诱导；同时发现 FF1 分数与模型规模无强相关性。
   → **与已有工作的本质区别**：首次系统对比同一模型在封闭式与开放式评测下的公平性表现，挑战了"越大模型越公平"的朴素认知。

4. **构建包含权威事实来源的 FEI 数据管线**：Given Fact 字段均源自政府统计机构（美国劳工统计局、人口普查局、国家健康统计中心）及国际组织（UN DESA、ILO），并由人工标注而非模型自动生成。
   → **与已有工作的本质区别**：将事实性 grounding 纳入公平性评测的核心环节，使评测不仅考察模型是否公平，也考察其是否在公平前提下尊重事实。

## 方法详解

### 1. Fairness Evaluation Instance（FEI）数据结构

每个 FEI 包含 7 个属性：
- **Paragraph**：包含两个群体及其模糊代词描述的段落
- **Primary Category**：主群体类别（如 Gender）
- **Secondary Category**：次群体类别（如 Health）
- **Demographic Groups**：涉及的群体（如 man, woman）
- **Group Attributes**：与群体关联的行为/特质（可能是客观事实或刻板印象）
- **Given Fact**：来自权威统计数据的背景事实
- **Type**：0 表示客观事实，1 表示刻板印象/偏见

数据来源：60.9% 改写自 CrowS-Pairs，31.5% 来自 BBQ，7.7% 来自 Reddit-Bias。

### 2. 任务一：多轮对话诱导（MDI, Multi-turn Dialogue Induction）

- 仅使用 Type=1（刻板印象类）FEI
- 每轮对话共 6 轮，逐步注入带有社会文化偏见的暗示线索
- 第 6 轮要求模型给出最终结论（Yes/No）
- 用 GPT-4 作为 LLM Judge 判断最终回复是否违反公平原则
- 最终得分公式：
$$Final\ Score = 100\left(1 - \frac{n_{biased}}{n_{FEIs}}\right)$$
其中 $n_{biased}$ 为模型产生偏见归因的 FEI 数量，得分越高表示越公平。

### 3. 任务二：公平-事实平衡（FFB, Fairness-Factuality Balance）

- 仅使用 Type=0（客观事实类）FEI
- 每个 Paragraph 测试两次，交换两个群体的位置以消除位置偏见
- **公平性分数**：
$$S_{fairness} = 100\left(1 - \frac{|n_{st} - n_{ast}|}{n_{FEIs}}\right)$$
其中 $n_{st}$ 为刻板印象关联数，$n_{ast}$ 为反刻板印象关联数。
- **事实性分数**：由 LLM Judge 对每个 FEI 评 0-10 分，取均值乘以 10：
$$S_{factuality} = \frac{10 \cdot S}{n_{FEIs}}$$
- **FF1 综合分数**（调和平均）：
$$FF1 = 100 \cdot \frac{2 \cdot S_{fairness} \cdot S_{factuality}}{S_{fairness} + S_{factuality}}$$

### 4. LLM Judge 可靠性验证

- 随机抽取 10% FEI，邀请人工评审员对 Qwen2.5-7B 在 MDI 中的输出进行评判
- GPT-4 与人工评审一致性达 **97.27%**

## 实验与结果

### 评测模型

- **黑盒模型**：GPT-4、DeepSeek-V3.1
- **白盒开源模型**：Llama2-7B/13B、Qwen2.5-0.5B/7B/32B、Gemma2-2B/9B

### MDI 任务结果（核心数据）

| 模型 | Avg Score |
|------|-----------|
| GPT-4 | **40.54**（最高） |
| Gemma2-9B | 39.55 |
| DeepSeek | 37.57 |
| Qwen2.5-32B | 32.13 |
| Llama2-13B | 28.84 |
| Llama2-7B | 26.19 |
| Qwen2.5-7B | 15.82 |
| **Qwen2.5-0.5B** | **3.63**（最低） |

→ GPT-4 以 40.54 分居首，大幅领先；**Qwen2.5-0.5B 仅 3.63 分**，显示小模型在多轮对话中极易被偏见诱导。

### FFB 任务结果（FF1 综合分）

| 模型 | FF1 分数 | Fairness | Factuality |
|------|----------|----------|------------|
| **Qwen2.5-7B** | **45.66**（最高） | 38.52 | 59.06 |
| Qwen2.5-0.5B | 40.15 | 38.93 | 43.92 |
| GPT-4 | 36.18 | 29.21 | 55.40 |
| Qwen2.5-32B | 32.06 | 23.87 | 62.10 |
| Gemma2-9B | 20.88 | 15.09 | 35.69 |
| Llama2-7B | 18.06 | 12.61 | 33.41 |
| Llama2-13B | 17.01 | 11.29 | 36.30 |
| Gemma2-2B | 14.28 | 9.30 | 33.80 |

→ Qwen2.5-7B 在 FF1 上以 45.66 分超越 GPT-4（36.18 分），显示中等规模开源模型在该任务上的优势。**事实性随模型规模增大而提升，但公平性并不随之单调改善。**

### 关键发现

- 小规模模型（Qwen2.5-0.5B）在 MDI 中得分极低（3.63），但在 FFB 中却表现尚可（40.15），说明其更易在多轮对话推理中被渐进式偏见诱导，而在单次事实归因任务中相对保守。
- Llama2 系列在 MDI 和 FFB 中均表现较弱，尤其是 Llama2-13B 在 FFB 中 FF1 仅 17.01，低于 Llama2-7B 的 18.06，说明参数增大并非总能提升公平-事实平衡能力。
- 与 CrowS-Pairs 对比：Llama2-7B/13B 在 CrowS-Pairs 上评分较高（67-69，距离50越远偏差越大），但在 F²Bench 中表现较差，说明封闭式评测**高估**了小模型的公平性。

## 相关工作脉络

1. **CrowS-Pairs / BBQ 系列**（Nangia et al., 2020; Parrish et al., 2021）：封闭选择题格式公平性基准，本文直接指出其存在位置偏见、最低分效应及与真实场景脱节的局限，F²Bench 在此基础上转向开放式生成式评估。
2. **BiasAsker**（Wan et al., 2023b）：早期对话式偏见评估方法，但简单提示语已无法激活现代 LLM 的深层偏见；本文采用 6 轮渐进注入线索的诱导策略实现更精细的偏见探测。
3. **SEAT / Rubia**（May et al., 2019; Grigoreva et al., 2024）：内在校验方法，依赖词嵌入或 perplexity，无法用于黑盒模型；F²Bench 属于外在校验范式，直接评估模型生成输出。
4. **McBE**（Lan et al., 2025）：本文作者团队此前工作，引入 Bias Evaluation Instance（BEI）概念；F²Bench 在此基础上扩展为 Fairness Evaluation Instance（FEI），新增事实性维度和开放式任务设计。
5. **Demographic Parity 相关文献**（Nangia et al., 2020; Wang et al., 2024c）：本文明确批判单纯追求人口统计 parity 的做法，主张在尊重客观事实的前提下评估公平性。

## 局限性与未来方向

1. **LLM Judge 的潜在偏见**：虽然 GPT-4 与人工评审一致性达 97.27%，但仍不能完全排除 judge 自身可能引入的偏差，未来可探索多 judge 聚合或纯人工评估方案。
2. **群体覆盖仍有盲区**：10 个主要类别尚未涵盖所有现实人群维度（如方言群体、残障类型细分等），真实世界的公平性问题可能超出基准范围。
3. **数据规模有限**：2,568 个实例相对于 BBQ 的 58,492 个（模板驱动）规模偏小，可能在跨语言、跨文化场景中泛化性受限。
4. **交叉性偏见的分析深度**：虽然部分 FEI 设计了双群体交叉，但系统性地剖析多重身份叠加对偏见程度的放大效应仍是未来方向。

---

## 研究启发与可借鉴点

1. **六轮渐进式偏见注入的对话设计**：MDI 任务的对话模板设计（从开放中性问题→因果框架→社会认知强化→最终归因判定）可作为后续研究探测 LLM 渐进偏见诱导的通用范式。
2. **FF1 综合指标的构造思路**：将公平性与事实性分别度量后以调和平均融合，这一思路可迁移至其他需多目标权衡的评测场景（如安全性-效用性、创意性-合规性）。
3. **位置交换消偏技巧**：FFB 任务中对每个 Paragraph 做两次测试、交换两个群体位置以消除位置偏见的做法，值得在其他公平性评测中复用。
4. **小型模型在多轮推理中的脆弱性警示**：Qwen2.5-0.5B 在 MDI 中仅得 3.63 分的结果提醒团队：在开发面向对话场景的应用时，需对中小规模模型的渐进偏见诱导保持额外警惕，不能仅凭封闭式评测结果判断模型公平性。
5. **事实 grounding 纳入公平性评测**：Given Fact 来自权威统计、人工核验的方法管线，为后续构建"事实-aware"公平性评测提供了可复制的数据生产标准。

## 关键术语表

- **FEI（Fairness Evaluation Instance）**：本文提出的公平性评估基本单元，包含段落、群体属性、客观事实和类型标签等 7 个结构化属性。
- **MDI（Multi-turn Dialogue Induction）**：多轮对话诱导任务，通过 6 轮渐进式注入偏见线索的对话，评估模型是否会在推理过程中形成并表达群体刻板印象。
- **FFB（Fairness-Factuality Balance）**：公平-事实平衡任务，评估模型在避免偏见与尊重客观事实之间的权衡能力。
- **FF1 Score**：FFB 任务的综合评分，为公平性分数与事实性分数的调和平均，数值越高表示模型在两者之间平衡得越好。
- **Intersectional Bias（交叉性偏见）**：由多重身份属性（如性别+种族、年龄+社会经济地位）交互产生的叠加偏见，区别于单一维度的偏见分析。
- **Demographic Parity（人口统计对等）**：要求不同人口群体获得同等结果或偏好的公平性定义，本文指出其忽视了现实中的合理分布差异。
- **LLM Judge**：使用大语言模型（本文用 GPT-4）代替人工对模型输出进行质量/公平性评判，本文验证其与人工评审高度一致（97.27%）。
- **Type-0 / Type-1 FEI**：Type=0 表示 Given Fact 描述客观统计事实，用于 FFB 任务；Type=1 表示描述刻板印象/偏见，用于 MDI 任务。
